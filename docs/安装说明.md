# 下载与安装说明

> 一句话：**代码即安装包。** 一条命令装进 DSH，或者自己从源码跑。

## 分发方式

鲸歌以**源码分发**：代码 MIT 开放，角色形象与动画作为独立的角色资产另行管理
（角色类项目常见做法，这样谁都能合法用代码，角色本身也有边界）。

所以装到的永远是最新代码。跑起来默认是标着 DEMO 的通用鲸鱼——
功能一个不少：窗口、交互、菜单、音乐、DSH 联动全都在。
有正式资产的人把文件放到本地对应目录即可，程序会自动使用。

## 方式一：装进 DSH（推荐）

前置：已经装了 DSH，终端里能跑 `dsh`。

```bash
dsh plugin --profile web add github:H-Canopy/dsh-whale-song
```

装完刷新 DSH Web 界面，她在**右下角**。

更新（重新拉一次）：

```bash
dsh plugin --profile web remove dsh-whale-song
dsh plugin --profile web add github:H-Canopy/dsh-whale-song
```

本地开发时可以直接 link 源码目录：

```bash
dsh plugin --profile web add "link:D:/你的路径/dsh-whale-song"
```

> 不要同时装上游的 `dsh-whale-girl-live2d`：两者插件 id 相同、前端都注册 `/dsh-pet/*`，
> 同时开可能只有一个能正常工作。

## 方式二：桌面独立版（不需要 DSH）

前置：Windows 10/11 + Node.js 18 以上。

```bash
git clone https://github.com/H-Canopy/dsh-whale-song.git
cd dsh-whale-song
npm install
npm run desktop:start
```

`npm install` 第一次会下载 Electron（几百 MB），慢是正常的。
启动后她直接出现在桌面上，透明、置顶、可拖动；DSH 没开也能用。

## 方式三：自己打包成 exe

```bash
npm run desktop:dist
```

产物在 `dist/` 下。**注意**：打出来的包会带上你本地的正式资产——
自己用可以，别传回仓库、Release 或网盘。

## 装完看到的是 DEMO 鲸鱼，正常吗

正常。仓库不带正式形象。要让程序用上正式资产，把资产放到本地 `assets/songm/`
（该目录已被 `.gitignore` 忽略，**不要提交**），具体范围见 [ASSET_POLICY.md](../ASSET_POLICY.md)。

## 常见问题

**装上了但右下角什么都没有？**
先确认插件真的装上了：`dsh plugin --profile web list`。
再确认没有同时启用上游那个包，并刷新页面。

**想先看看长什么样，不想装？**
`npm install` 之后跑 `npm run preview`，浏览器里就能看。

**更新要重新装吗？**
`remove` 再 `add` 一次最省事；本地 link 的，拉代码后重启 DSH。

**她能干什么？**
见 [功能.md](功能.md)。
