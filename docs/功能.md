# 鲸歌能做什么

> 这一页是完整功能说明。装法见 [README](../README.md)。

## 她是谁

一只住在你电脑桌面上的鲸。蓝色长发、鲸鱼连帽斗篷，常态是「左手本子、右手笔」，
平时安安静静待在屏幕角落，干活时会有表情和动作。她不是静态壁纸——
她能读到 agent 在干什么，也能被你点、被你拖、被你支使去放歌。

## 三种运行形态

| 形态 | 需要什么 | 她有什么 |
| --- | --- | --- |
| **DSH 插件** | DSH Web 界面 | 全部：对话、任务状态、钱包、简报、音乐 |
| **桌面独立版** | Node.js + Windows | 模型、物理、表情动作菜单、音乐；DSH 开着时才多出联动 |
| **单页预览** | 浏览器 | 只看、只点，用来验证渲染 |

## 交互

| 操作 | 她怎么反应 |
| --- | --- |
| 点一下她 | 说句话；手上做个小动作 |
| 同一处 500ms 内再点 | 打开对话框，直接跟 agent 说话 |
| 右键 | 打开菜单（六个页签，见下） |
| 拖动 | 整窗跟着走；拖到屏幕边缘会被夹回来，不会掉出去 |
| 双击右键 | 播放 / 暂停当前音乐 |
| 闲置一会儿 | 自己慢慢挪个位置（你在拖动或打字时会自动停下） |

窗口本身：透明、置顶、可穿透（透明区域不挡鼠标）、可收起、缩放 150–280。
位置按「角色在屏幕上的锚点」记忆，换分辨率或拔掉显示器也会夹回可见区。

## 右键菜单

六个页签：**表情 / 装饰 / 场景 / 动作 / 音乐 / 设置**。

### 表情（44 个）

手动选的表情是**临时**的：演 3–4 秒就让位给她自己的状态。
平时她按 agent 的状态自动换脸——你说她一句，她可能就 `脸红`；
任务报错，她会 `流汗`；活干完了，她会是 `开心兴奋`。

常用：`星星眼` `爱心眼` `脸红` `开心兴奋` `悲伤` `哭` `生气` `调皮` `晕晕` `阴暗` `流汗` `问号` `感叹号` `闭眼口水` `吐舌` `吐魂`。

### 装饰（11 项，戴上就不摘）

圆眼镜 / 方眼镜 / 椭圆眼镜 / 墨镜 / 猫猫贴纸 / 兔兔贴纸 / 蝴蝶结贴纸 /
情绪花花 / 单边马尾 / 发箍 / 头顶鲸鱼。

同类互斥（眼镜一次只能戴一副），再点一下摘掉。

### 场景（7 项，摆着不走）

深色桌布 / 鲸鱼放桌上 / 桌面巴菲 / 粉魔爪 / 白魔爪 / 掏出手机 / 手机换色。

有几个有前置关系：`白魔爪` 要先有 `粉魔爪`，`手机换色` 要先 `掏出手机`——
点的时候她会自动补齐前置，不用你自己先摆一遍。

### 动作（12 项，演一次就消失）

猫爪摆手 / 喵喵手 / 双手比耶 / 冒爱心 / 心跳 / MoeMoeQ~ / 橡皮擦 / 撤回 /
鲸鱼喷水 / 蛋包饭 / 自拍 / 快速自拍。

每个动作都配一句台词。蛋包饭是「挤番茄酱」的一整套表演，演完桌上的饭会收走，
不会一直摆着。

### 音乐

- 本地音乐：选一个文件夹，列歌单，直接播。
- 在线电台：Radio Browser、SomaFM。
- 网易云联动：遥控播放 / 点歌 / 歌单；点歌走对话，不在面板里做搜索框。
- 优先走系统媒体会话（SMTC）；部分网易云版本需要短暂激活窗口才能控制，属于兼容做法。

### 设置

缩放、位置、简报开关、显示内心想法、开机自启等，改完就存，关掉再开还是你设的样。

## 和 DSH 联动的部分

- **对话**：点她就能说话，她说的话会显示在气泡里。
- **任务状态**：待机 / 思考 / 干活 / 出错 / 完成，她会有不同的表情和动作。
- **钱包**：余额和花费额度显示在菜单里；累计消费到阈值，她会冒个气泡提醒一次。
- **工作简报**：头顶的信封，点开是大号简报面板，每条可以叉掉。

## 公开示例和正式版的差别

公开仓库不带正式角色资产，跑起来是标着 `DEMO` 的通用鲸鱼：

| | 公开示例 | 正式资产版 |
| --- | --- | --- |
| 模型与物理 | 通用鲸鱼 | 鲸歌 |
| 表情 / 装饰 / 场景 / 动作 | 通用鲸鱼自带的少量 | 44 表情 / 11 装饰 / 7 场景 / 12 动作 |
| 视频动作（待机、阅读、哈欠、伸懒腰、转圈、跑步） | 无 | 有 |
| 交互、音乐、DSH 联动 | 有 | 有 |

正式资产为什么不在仓库里，见 [ASSET_POLICY.md](../ASSET_POLICY.md)。
