### 关键结论：**"闪"和"抓不住"曾经是同一个机制**
旧机制 = `setIgnoreMouseEvents(true,{forward:true})` + 每 90ms 轮询切穿透。证据：
- `forward:true` **只转发移动、不转发按键** → 切成穿透时按下被桌面吃掉（日志：只有 `mouseup` 没有 `mousedown`）；
- 每次切 `WS_EX_TRANSPARENT` = **整窗重新合成** = 闪（用户原话："指针一靠近她就闪"）。

**整套已删除**（`main.js:134` 有墓碑注释），窗口永远可交互，命中判定交给页面里的掩码 `hitTest`。
代价：窗口左上角透明空白不再穿透、会挡鼠标。

### 关键结论：**拖动节拍不能用 `setInterval`**
Windows 计时器粒度 15.6ms → `setInterval(33)` 实际是 **46.6ms/帧（21fps）**；
自校正 `setTimeout` 才能跑满 **33.0ms**。另外 `tick` 里**只允许 1 个 `return`**
（多一个 = 调度在末尾到不了 = 拖动永久冻死，外部评审抓到的）。

## 4. 真实踩过的坑（新对话里别再踩）

### 生成器相关（**踩得最多**）
1. **`main.js` / `preload.js` / `window-shape.cjs` / `server.cjs` 都是生成物** → 必须改生成器。
   （我因为直接改生成物丢过诊断代码；外部评审也踩了这条。）
2. **生成器只在文件末尾写盘一次** → 所有注入必须在它之前（⑱/⑲ 都因此白改过）。
3. **单引号字符串里的中文双引号 `"…"` 会截断字符串**（踩了三次）。
4. **断言必须放在对应注入之后**，且**先过滤注释行**再匹配（否则注释里提到的 API 名会误报）。
5. **别用带常量名的精确正则定位**（`expand: 6,` 那条就因为带了 `OFFSET` 而静默没匹配上）。
6. **断言别写会匹配自身的模式**（我写的 `stripBom` 断言把自己实现里的 `stripBom` 也算进去了）。

### 环境相关
7. **壳的 preload 跑在沙箱里**（`webPreferences` 没关 `sandbox`）→ **不能用 `require('node:fs')`**，
   诊断必须走 IPC。（我第一版诊断因此静默失败 → 误判成"preload 没跑"。）
8. **`settings.json` 的 UTF-8 BOM 会让 `JSON.parse` 抛错并被 `catch` 吞掉** → 开关静默失效。
9. **PowerShell 的 `>` 重定向是 UTF-16**，会把文件写坏（我就这样弄坏过一个 .js，`node --check` 才发现）。
10. **PowerShell 里内联 node 脚本会被 `$` 变量插值破坏**（`$pad`、`$args` 会被吃掉）→ 写成 .mjs 文件再跑。
11. **`sendInputEvent` 注入的点击绕过操作系统** → 不能用来验证区域裁剪/穿透这类 OS 层行为。
12. **DSH 会话里有 `ELECTRON_RUN_AS_NODE=1`** → 在 DSH 终端里起 Electron 前必须清掉。
13. **合成鼠标的"按下"到不了 Electron 页面**（普通 WinForms 窗口能收到，已对照验证）→
    **自动化测拖动在这台机器上不可行**，只能真人拖 + 读日志。
