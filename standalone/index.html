跟她说话（把话送进会话）—✅
想让她真的干活？
装进 DeepSeek Harness 就是完整版（跟着 agent 联动 + 懂音乐 + 能点歌）：
dsh plugin --profile web add github:H-Canopy/dsh-whale-song
装完重启一次 DSH，右下角就会出现她；这一页可以关掉了。
